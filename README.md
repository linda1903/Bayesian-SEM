# Bayesian Structural Equation Model — *Fagus sylvatica* light gradient

Bayesian SEM testing directed causal paths between light environment,
gene expression, and photosynthetic performance in European beech
(*Fagus sylvatica*). This script is part of a doctoral project at the
Senckenberg Biodiversity and Climate Research Centre (SBiK-F), Frankfurt.

**Manuscript in preparation.** Code and data are shared to support
transparency and reproducibility.

---

## Data availability

Raw sequencing reads and sample metadata are publicly available on the
European Nucleotide Archive (ENA) under accession
**[PRJEB64934](https://www.ebi.ac.uk/ena/browser/view/PRJEB64934)**.

The dataset comprises 185 mRNA-seq samples from 28 *F. sylvatica* trees
sampled at seven canopy positions (leaf positions 1–7, shade to full sun),
with paired photosynthetic performance measurements (PI~abs~, Fv/Fm) and
light intensity (lux, relative exposure).

---

## Model

The SEM tests four directed causal paths:

```
Leaf position ──→ Gene expression PC1 ──→ PIabs
      Lux ────────────────────────────────────↗
```

Gene expression PC1 is the first principal component of 15,126
leaf-position-responsive genes (explaining 20.3% of transcriptomic
variance), computed in the companion WGCNA pipeline.

Two sub-models are fitted jointly via brms:

| Sub-model | Formula | Family |
|-----------|---------|--------|
| Gene expression | `pc1_std ~ mo(pos) + lux_std + (1\|genotype)` | Gaussian |
| Photosynthesis | `mean_pi_abs ~ lux_std + pc1_std + (1\|genotype)` | Gamma (log link) |

`mo(pos)` uses brms monotonic effects for the ordered leaf position factor (1–7),
separating the developmental positional gradient from the acute light intensity effect.
Priors: normal(0,1) on all fixed effects; gamma(2,0.1) on the Gamma shape parameter.
4 chains × 5,000 iterations (1,000 warmup); adapt_delta = 0.95.

**Results:** All four paths are credible (95% posterior CI excludes zero).

| Path | β (posterior median) | 95% CI |
|------|---------------------|--------|
| Lux → PC1 | 0.45 | [0.32, 0.58] |
| Leaf position → PC1 | 0.11 | [0.06, 0.16] |
| Lux → PIabs | −0.10 | [−0.16, −0.05] |
| PC1 → PIabs | −0.11 | [−0.16, −0.05] |

## Input

The script requires one input file:

| File | Description |
|------|-------------|
| `sem_data.csv` | Pre-computed SEM input data — 183 samples × variables (pc1_std, lux_std, mean_pi_abs, pos, genotype, condition_num). Generated by the companion [WGCNA pipeline](https://github.com/leberhardt91) from ENA accession PRJEB64934. |

`sem_data.csv` contains the standardised gene expression PC1 scores
alongside photosynthetic trait and light intensity measurements for each
sample. It is available from the WGCNA repository or on request from
the corresponding author.

---

## Output

| File | Description |
|------|-------------|
| `sem_bayesian_fit_no_fvfm` | Saved brms fit object (auto-reloads on re-run if unchanged) |
| `sem_trace_plots_no_fvfm.pdf` | MCMC trace plots and density plots for convergence checking |
| `sem_path_coefficients_no_fvfm.csv` | Path coefficients — posterior median + 95% CI for all four paths |
| `sem_r2_no_fvfm.csv` | Bayesian R² per sub-model (mean + 95% CI) |
| `sem_conditional_effects_pc1.pdf` | Conditional effects: gene expression PC1 sub-model |
| `sem_conditional_effects_piabs.pdf` | Conditional effects: PIabs sub-model |
| `sem_path_diagram_no_fvfm.pdf` | Path diagram with posterior estimates |

## Dependencies

```r
install.packages(c("brms", "dplyr", "ggplot2"))
```

| Package | Purpose |
|---------|---------|
| brms | Bayesian multilevel models via Stan |
| dplyr | Data manipulation |
| ggplot2 | Path diagram and visualisation |

brms requires a working Stan installation. See the
[brms documentation](https://paul-buerkner.github.io/brms/) for setup
instructions. The full R session info will be added on manuscript submission.

---

## Usage

```r
# Place sem_data.csv in the working directory, then:
source("sem_fagus_lightgradient.R")
```

Runtime: approximately 10–20 minutes (4 cores). The fitted model is cached
to disk (`sem_bayesian_fit_no_fvfm`); re-running the script reloads the
cached fit automatically if the model and data have not changed.
